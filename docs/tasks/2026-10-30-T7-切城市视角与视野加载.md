## §0 背景

**现状**：`loadCityPois()` 一次拉全城且被 `limit:5000` 卡住（杭州库中 **12786** 条 ⇒ 只能拿到 5000，饣 60%）；

**用户要**：切城市 → 落**主城区** → **合适倍率** → **然后**才加载地图上的信息；
并且（2026-10-30 追加）「**加载的东西还是少**」＋「**地图到一定倍数之后才显示**」。
（实测：高德城市 `center` 就是主城区，杭州落点上城区钱江新城市政府。）

## §2 T1 · 后端：bbox 过滤

- `GET /api/pois` 新增 `bbox=minLng,minLat,maxLng,maxLat`
- 校验：四段都可解析为数字、`minLng<maxLng`、`minLat<maxLat`，否则 **400**
- SQL 加 `lng BETWEEN ? AND ? AND lat BETWEEN ? AND ?`
- 与 `category` / `minRating` / `sort` / `limit` / `offset` 可叠加；无 `bbox` 时行为**逐字节不变**

## §3 T2 · 前端：先定位后加载 ＋ 视野加载

- `map.js`：暴露 `getBounds()`、`onMoveEnd(cb)`（内部防抖 300ms）、`setZoomAndCenter(lng, lat, zoom)`
- 切城市流程：
  1. 状态提示「定位中…」
  2. 清空旧旗子
  3. `setZoomAndCenter(center, CITY_ZOOM=13)`
  4. **等 `moveend`** 后才 `fetchPoisInView()`
- `fetchPoisInView()`：
  - 取 bounds → bbox → `GET /api/pois?city=&category=&minRating=&bbox=&limit=`
  - **递增请求序号**，只应用最后一次响应（丢弃过期）
  - 落旗 + 刷列表 + 更新计数「当前视野 N 条 · 全城已收录 M 条」
  - **倍率阈值（唯一门控）**：`zoom < MIN_MARKER_ZOOM`（默认 **13**）→ **不发请求也不画点**，只提示「放大地图以加载本区域地点」
- **不要任何数量限制**（用户原话「不要有限制」）：不加 `limit` 封顶、不做抽稀；点多少画多少
- **取消 `limit:5000`**：改为按 bbox 拉；后端 `limit` 仅作防御（默认不给就在 bbox 内全量返回）
- 地图 `moveend` → 自动 `fetchPoisInView()`（用户拖到哪加载到哪）
