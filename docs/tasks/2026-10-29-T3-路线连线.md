## §2 T1 · 后端：三种路径规划封装（`server/amap.js`）

- `planWalking(origin, destination)` → `GET /v3/direction/walking`
- `planDriving(origin, destination, strategy?)` → `GET /v3/direction/driving`
- `planTransit(origin, destination, city)` → `GET /v3/direction/transit/integrated`（**`city` 必填**）
- `parsePolyline(str)` → `[[lng,lat],…]`（高德格式 `"lng,lat;lng,lat;…"`）
- **统一归一化**成同一形状：
  ```json
  { "mode":"driving", "distance":3200, "duration":720,
    "polyline":[[120.1,30.2],[…]],
    "steps":[{"instruction":"…","distance":…,"duration":…,"polyline":[…]}] }
  ```
- 公交特殊：从 `route.transits[0].segments[]` 里把 `walking.steps[].polyline` 与
  `bus.buslines[].polyline` **按顺序拼成一条完整折线**；`transit` 字段额外带回换乘摘要
- 复用现有 `amapGet` 的错误归一（`AMAP_ERROR`）
- **所有失败路径都不许把整个请求拖垮**：段级失败由上层捕获

## §3 T2 · 后端：两个接口（`server/routes/route.js`）

- `GET /api/route?mode=&origin=&destination=&city=`
  - `mode` ∈ `walking|driving|transit`，非法 → `400`
  - `origin`/`destination` 必须是 `lng,lat`，格式错 → `400`
  - `transit` 缺 `city` → `400`
  - 成功 → 归一化结果；高德报错 → `502` + `AMAP_ERROR`
  - 走缓存（键：mode+origin+destination）
- `GET /api/itinerary/route?city=&mode=`
  - 取该城行程的已选点（T2 的 `getSelectionByCity`，按 `sort_order`）
  - 点 < 2 → `400`
  - **逐段串行**规划，段间留间隔；每段独立 try
  - 返回：`{mode, legs:[{index,from,to,distance,duration,polyline,ok,degraded,reason?}], totalDistance, totalDuration, failed:[…]}`
  - **部分失败 → HTTP 200**；一段都成功不了 → `502`
