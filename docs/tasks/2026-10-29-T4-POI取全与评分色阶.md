## §2 T1 · 后端：采集器（`server/collect.js`）

- `districts(city)` → 高德行政区划查询，拿该城市下辖区县的 `(name, adcode)`
- `collectCityCategory(city, category, onProgress)`：
  ```
  for 区 in districts:
      for page in 1..8:
          pois = amap.searchPoiByDistrict(区adcode, 分类词, 分类码, page)
          if not pois: break                 # 取到没有为止
          过滤 typecode 前缀不匹配的           # 分类纯净
          按 poi_id 去重入库（INSERT OR REPLACE / 增量统计）
          onProgress(...)                    # 写进度
  ```
- 串行 + 每次请求间留间隔（复用 settings 的 `http_min_interval`）
- **逐区 try/catch**：某区失败 → 记 warning、跳过该区、继续下一区；整轮结束若有过失败 → `status=partial`
- **二级分片兜底**：某区取到 200（被截断）→ 对该区中心做周边搜索细分（半径递减），直到没有为止
  （若时间不够，**允许先只做行政区一级分片并在 §7.4 记明**）

## §3 T2 · 后端：缓存表与接口（`server/routes/pois.js`）

- 表结构见需求增补 §3（`pois`、`poi_collect_runs`），幂等迁移
- `POST /api/collect` `{city, category?}` → 后台起采集（不阻塞），返回 `{runId}`；同 (城市,分类) 已在跑 → `409`
- `GET /api/collect/status?runId=` → 进度（`percent` 按已完成区数/总区数）
- `GET /api/collect/runs?city=` → 各分类最后采集时间与条数
- `GET /api/pois?city=&category=&sort=&limit=&offset=` → **只读缓存**，`sort=rating` 按评分降序（空评分排最后）
- `GET /api/pois/stats?city=` → 各分类条数 + 评分分布分桶（供图例）

## §4 T3 · 前端：色阶与数据源

- `web/js/score-color.js`：`colorFor(categoryKey, rating)` → 分类基准色转 HSL，`L` 在 `72%→34%` 之间按评分 `[3.0,5.0]` 归一映射；无评分 → 最浅 + 灰边
- 地图旗子用 `colorFor(...)` 着色；**保持分类色相不变**
- **色阶图例**：地图角落一条渐变条 + 「3.0 / 4.0 / 5.0」刻度
- **结果列表数据源切到 `/api/pois`**（缓存）；保留 `搜索框`走实时 `/api/poi/search`
- 缓存为空 → 显示「该城市还没采集」+「开始采集」按钮
- **采集进度**：点了采集后轮询 `/api/collect/status`，显示「正在采集 5/13 区，已入库 823 条」，完成后自动刷新列表
