## §2 T1 · 后端：覆盖记录

- 表结构见需求增补 §2；常量 `GRID_DEG = 0.01`
- `gridOf(lng, lat)` → `{gx, gy}`；`bboxToGrids(bbox)` → 格列表（含边界，注意最大格数上限，防超大 bbox）
- `isCovered(city, category, gx, gy)` / `markCovered(...)`
- **注意**：bbox 过大（格数 > 上限，如 400）→ 不采，返回提示（前端处于低倍率时本来也不该采）

## §3 T2 · 后端：按视野采集

- `POST /api/collect/viewport {city, bbox, category}`：
  - 取 bbox 内的格 → 过滤掉已覆盖的 → **只为剩余格采集**（按每格中心做周边搜索，或用 bbox 多边形搜索）
  - 逐格串行 + 间隔（复用 T4 的 `intervalMs` / `sleep`）
  - 每格采完 `markCovered`
  - **合并**：同一 `(city,category,grid)` 已在跑 → 不重复起
  - 返回 `{runId, grids:[…]}`，进度走既有 `/api/collect/status`
- `GET /api/coverage?city=&bbox=&category=` → `{grids:[{gx,gy}], uncovered:[{gx,gy}]}`
- **缩小时不采是前端责任**，但后端也校验：bbox 格数超上限 → `400` 并说明

## §4 T3 · 前端：自动采集与渐进补旗

- `moveend`/`zoomend`（沿用 T7 防抖 300ms）后：
  1. `zoom < MIN_COLLECT_ZOOM`（13）→ 清点 + 提示「放大地图以加载本区域地点」；**不发任何采集请求**
  2. `zoom ≥ 13` → 先按 bbox 读缓存 → **立即落旗**（有多少画多少）
  3. `GET /api/coverage` → 有未覆盖格 → `POST /api/collect/viewport`（自动）→ 提示「本区域加载中…」
  4. 完成后**重读 bbox 缓存 → 增量补旗**（不整体重画，避免闪烁）
- 前端记录「正在采的格」，避免重复触发
- T4 的「开始采集」按钮文案改「采集全城（补全）」
