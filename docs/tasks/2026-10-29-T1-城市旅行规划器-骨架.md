## §0 背景

用户在计划城市旅行时，需要把「想住的/想吃的/想玩的/想看的」都标在地图上看分布，形成出行清单。

**产品**：选城市 → 看该城推荐地点 → 按 4 个分类过滤 → 搜索定位 → 地图落旗（不同分类不同颜色/图标）→ 存成行程。

**数据源已定**（勿重新论证）：高德 POI 为主力；小红书/抖音**只做跳转**，不抓取。

## §2 T1 · 项目骨架

- `server/config.js`：读 `config/local.json`（不存在则读 `config/example.json` 并给出明确报错提示）；导出 `{port, amap:{webServiceKey, jsApiKey, jsApiSecurityCode}, defaultCity}`
- `server/index.js`：
  - `node:http` 起服务，监听 `config.port`（默认 8787）
  - 路由分发（方法 + 路径），`/api/*` 走接口，其余走 `web/` 静态托管
  - 统一响应包装 `sendOk(res,data)` / `sendErr(res,status,code,msg)`
  - 未匹配路径 → 404 JSON；静态文件不存在 → 404
  - 启动时打印 `服务已启动: http://127.0.0.1:<port>`
- `GET /api/health` → `{ok:true,data:{status:"up",uptime:<秒>}}`
- `GET /api/config` → `{ok:true,data:{jsApiKey, jsApiSecurityCode, defaultCity, categories:[…]}}`
  （`categories` 读 `config/categories.json`）
- `scripts/start.sh`：`exec node server/index.js`

## §3 T2 · 后端：高德代理层（`server/amap.js` + `server/cache.js`）

**统一封装**，所有高德 REST 调用走这里：

- `amapGet(path, params)` → 拼 `key`、`fetch`、解析；`infocode !== "10000"` 或 `status !== "1"` 时抛错（带上高德 `info`/`infocode`）
- `searchCity(q)` → `GET /v3/config/district?keywords=<q>&subdistrict=0&extensions=base`，只保留 `level==="city"` 的项
- `searchPoi({city, category, keywords, page})` → `GET /v3/place/text`
  - `keywords` 缺省时用分类的通用词（如美食→`美食`）；有 `keywords` 时用用户输入
  - `city` 传城市中文名；`page` ≤ 25（每页最多 25 条，翻页最多 200 条总量）
  - `extensions=all`（要 `biz_ext` 的 rating/cost、`photos`、营业时间）
- `nearbyPoi({lng, lat, category, radius})` → `GET /v3/place/around`
- `poiDetail(id)` → `GET /v3/place/detail`
- **归一化**：把高德原始 POI 转成内部结构（前端只认这个）：
  ```json
  { "id":"B0I1ODBA7N", "name":"…", "address":"新业路228号杭州来福士广场4楼",
    "lng":120.212943, "lat":30.249170, "typecode":"050202", "type":"餐饮服务;…",
    "category":"food", "rating":"4.7", "cost":"172.00", "tel":"…",
    "opentime":"周一至周日 11:00-14:30,17:00-21:30", "photo":"https://…", "tags":["…"] }
  ```
- **分类判定**：`typecode` 前缀匹配 → `category` key（`050000`→food，`100000`→stay，`110000`→sight，`080000`→play；都不匹配则 `null`）
- `server/cache.js`：内存 Map，键 = 完整请求参数串，TTL **600 秒**；命中直接返回，不算配额；导出 `get/set/stats`

**接口**（详见需求文档 §6）：

| 方法 | 路径 |
|---|---|
| GET | `/api/city/search?q=` |
| GET | `/api/poi/search?city=&category=&keywords=&page=` |
| GET | `/api/poi/nearby?lng=&lat=&category=&radius=` |
| GET | `/api/poi/detail?id=` |

**错误约定**：高德失败 → HTTP `502`，`{ok:false,error:{code:"AMAP_ERROR",msg:"<高德 info 原文>"}}`。

## §5 T4 · 前端（`web/`）

**布局**：左侧栏（城市选择 + 搜索 + 分类 chip + 结果/行程列表）＋ 右侧地图（占满）。

1. **`web/js/api.js`**：封装 `fetch`，统一解包 `{ok,data,error}`，失败抛错
2. **`web/js/categories.js`**：从 `/api/config` 取分类定义；提供 `colorOf(key)` / `labelOf(key)` / `iconOf(key)`
3. **`web/js/map.js`**：
   - 动态加载高德 JS API（`https://webapi.amap.com/maps?v=2.0&key=<jsApiKey>&plugin=AMap.Geocoder,AMap.PlaceSearch`）
   - 若配置了 `jsApiSecurityCode`，先设 `window._AMapSecurityConfig`
   - `init(el)` / `flyTo(lng,lat,zoom)` / `addMarker(poi)` / `clearMarkers()` / `fitView()`
   - **旗子按分类着色**：用 `AMap.Marker` 的 `content`（自定义 HTML 小旗，颜色取分类配置）或官方 `icon`（`new AMap.Icon` 指定颜色）；**不同分类必须视觉可区分**
   - 点击 marker → 回调 `onMarkerClick(poi)`
   - 地图 SDK 加载失败 → 页面显示明确错误，不白屏
4. **`web/js/ui.js`**：
   - 分类 chip（可多选/单选：**做成多选**，全部取消 = 显示全部）
   - 结果列表项：名称 + 分类色点 + 地址 + 评分/人均
   - **信息卡**（点 marker / 列表项弹出）：名称、**详细地址（可复制）**、评分、人均、电话、营业时间、图片；
     两个按钮：`[导航]`（`https://uri.amap.com/marker?position=lng,lat&name=<名>` 新窗口）、`[去小红书看笔记]`（`https://www.xiaohongshu.com/search_result?keyword=<城市+店名>` 新窗口）
   - 「加入行程」按钮 → `POST /api/pins`
5. **`web/js/app.js`**：串流程 —— 启动 → 取 config → 初始化地图 → 载入默认城市（`杭州`）→ 拉默认 POI 列表 → 渲染
6. 城市切换：搜索城市 → 选中 → `flyTo` 城市中心（用高德城市中心点，取 `district` 返回的 `center`）→ 重拉 POI
7. 窄屏（<800px）：上下布局可用
