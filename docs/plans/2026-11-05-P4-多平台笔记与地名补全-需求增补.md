# P4 需求增补：多平台笔记（图文/视频）→ 本地库 → 提取地名 → 高德补全

- 日期：2026-11-05
- 触发：用户 2026-11-04 定「**先做按照笔记搜索地方，笔记区分来源，下载后缓存到本地，之后从我这读取**」，
  随后 2026-11-05 补口径「**小红书 抖音 快手 等等，笔记和视频都可以**」
- 前置：P3（`86a1a7f`）已经做好「笔记本地库 + 落图 + `/notes-img` 静态出图」，本档把它接到**页面**与**地点**上

## 1. 一句话

把「在哪个平台、看到哪条笔记/视频」→「粘一段分享文案」→（本地库）→「正文里提到的地方」
→（高德补全）→「能在地图上看、能加入我的选择」这条链路打通；**平台侧一律不抓**。

## 2. 口径（本轮锁定）

| # | 决定 | 依据 |
|---|---|---|
| D1 | 内容来源＝**用户粘贴**（分享文案/链接/正文 + 可选图 URL），不做平台抓取 | P3 实测：抖音（无 OG、登录态弹验证码页）、小红书（302 / `error_code=300012`）、B站（风控页）、微博（302 访客登）本机全不通 |
| D2 | 支持平台：小红书 / 抖音 / 快手 / B站 / 微博 / 微信，其余落「其他」 | 用户口径「等等」 |
| D3 | 内容形态 `kind`：`note`（图文）/ `video`（视频，含封面）；抖音/快手/B站默认 video，小红书/微博/微信默认 note | 用户「笔记和视频都可以」 |
| D4 | 视频**只存链接 + 封面**，不下载视频本体 | 平台视频源要登录态才能拿；封面是列表可视化的最小必需 |
| D5 | 「提取地名」＝**零调用、可反复跑**；「高德补全」＝**每个名字 1 次调用，最多 8 个** | 用户在意 token/配额成本；高德搜索服务 30 元/万次且不享折扣 |
| D6 | 补全失败（配额/网络）如实回报、**不写假点**（该名字留空，可重试） | 与 P2「失败一律不标覆盖」同一立场 |
| D7 | 地名候选**可改**（页面输入框，顿号/逗号/空格分隔） | 抽取是启发式（会捞到「杭州咖啡」这类噪声），把决定权交给用户 |
| D8 | 图/封面下到本地（`data/notes-img/`，sha1 命名，按 URL 幂等），页面只读本地 | P3 既有能力；用户「下载后缓存到本地，之后从我这读取」 |
| D9 | 不改 P3 语义：`images` 仍是正文图条，封面单列 `cover`/`cover_url`；老库靠 `ensureColumn` 前滚 | 兼容既有数据与 291 条用例 |

## 3. 落地

**服务端**
- 新 `server/note-share.js`（纯函数，零依赖）：`parseShareText`（平台/形态/标题/作者/链接）、
  `cleanContent`（正文初值：去链接/引导语/标题/作者/模板残渣）、`extractPlaceNames`（地名候选）、
  `sourceOfUrl`/`extractUrl`/`hostOf`。
- `notes` 表加 `kind` / `video_url` / `share_text`；新表 `note_places`
  （`note_id, name, poi_name, city, poi_id, address, lng, lat, rating, category, photo, resolved_at`）。
- 路由：`POST /api/notes/parse`（解析，不落库）、`GET /api/notes/:id`（含 places）、
  `POST /api/notes/:id/places`（`{names?, resolve?}`，整批替换、幂等）、`DELETE` 连带删地点；
  `POST /api/notes` 支持 `share_text`/`kind`/`video_url`/`cover_url`，**url 不再是必填**
  （`url`/`share_text`/`title` 至少给一个）。
- 列表/搜索返回加 `place_count`（一次 `GROUP BY`，不逐条查）。

**前端**
- 左栏新卡片「笔记 → 找地方」：粘贴框（**粘上自动识别**）→ 平台/形态/标题/作者/正文/图 URL 可改 → 存到本地；
  下面是本地笔记列表（来源角标 + 图文/视频 + 地点数 + 封面缩略图）。
- 详情：封面、正文、图条、原链接/视频链接 + 「提取地名」「高德补全」「删除」+ 地名输入框 +
  每个候选地点带「加入选择」「地图」（走既有 `Selection.select` 与 `MapCtl.flyTo(…,16)`）。
- 图挂了（本地缓存被清/防盗链）自动隐藏，不留破图框。
