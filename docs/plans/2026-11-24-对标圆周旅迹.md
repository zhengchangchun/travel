# 旅迹 vs 圆周旅迹（Pi Travel）：差距与这轮补的（2026-11-24）

> 因由：用户「你可以对比下圆周旅迹这个产品，优化下整体」。
> 圆周旅迹的信息取自其官网博客（5.0 功能指南）与第三方介绍页，**都是它自己的宣传口径**，未亲测。

## 一、它有什么（按它自己的说法）

| 能力 | 细节 |
| --- | --- |
| 一键抄作业 | 粘小红书/抖音/公众号链接 → 提取景点/餐厅/住宿 → 勾选 → 自动排线 |
| **多条整合解析（5.0）** | **一次粘 10 条链接并行解析**，自动去重汇聚；图片最多 9 张同时识别 |
| AI 生成行程 | 说目的地+天数+偏好，多轮追问后出按天行程，约 3 分钟；**语音输入** |
| 对话改行程 | 直接说「换地点/调顺序/增减天数」，AI 改；**展示推理过程** |
| 多人协作 | 协作链接邀请，多人同时编辑、实时同步 |
| 地图导览 | **每天一种颜色**、景点按顺序编号、每段距离与用时、天气与交通自动补全 |
| 附近推荐 | 按当前停留位置推附近小店/打卡点 |
| 首页动态 | 按阶段（出发前 N 天 / 前一天 / 旅途中）主动提示，算出门时间 |
| 离线 | 离线地图缓存 |
| 分享 | 海报、长图、口令 |

## 二、我们已有的（不输的）

- **笔记 → 地名 → 地图**：贴链接自动抓（本机浏览器登录态），提取地名、高德补全成候选点 —— 与它的「一键抄作业」同一条链。
- **地图上挑点 + 实时耗时**：四种出行方式逐段实测，比它的「自动补全交通」更实（我们是真调路径规划）。
- **按天分段 + 拖拽调序 + 自动成线**：它靠对话改，我们靠手改 —— 各有各的顺手。
- **分享三件套**：自包含 HTML（不依赖网络/账号）+ 纯文本 + JSON，比海报更「能直接用」。
- **数据自持**：库在本机 SQLite，实景图只用自由许可 —— 它做不到。

## 三、这轮补的三件（都是它明显强、我们明显缺的）

### ① 一次粘多条链接一起解析（对标它的 5.0 核心卖点）

- 后端：`extractUrls()` 取全部链接（去重保序）→ 新任务 `kind=fetch-many` → `fetchManyAndIngest()`
  **逐条抓、逐条落库**，一条失败不影响其他条，上限 10 条，超出的如实报「跳过 N 条」。
- 前端：粘进去的文案里有 >1 个链接就自动走批量，报「抓到 N / M 条 · 失败 K 条：原因…」。
- 实测：无链接 → 400「这段文字里没找到链接」；两条不可识别域名 → 任务跑完 `{total:2, ok:0, failed:2}`，
  每条各自带 `BAD_PLATFORM` 原因（**不整批白跑**）。

### ② 多天行程按天配色（对标它的「每天一种颜色」）

- `map.js` 新增 `DAY_COLORS` + `dayStyle()`；`route.js` 只在**多天**时把 `days[]` 交给地图。
- **单天不启用** —— 单天仍按出行方式配色（那套颜色是图例语义，不能被天数顶掉）。
- 实测三亚那趟（9 点，前 3 点挪到第 2 天）：地图上第 1 天蓝、第 2 天橙，一眼分得开。

### ③ 行程总览读数（对标它的「行程总览」）

- 路线读数行多一格：`2 天 · 6 点 · 3 点`（几天 + 每天几个点），只在多天时出现。

## 四、还差的（按「值不值得做」排）

| 差距 | 我们的现状 | 值不值得补 |
| --- | --- | --- |
| **多人协作编辑** | 分享页只读；搭子只是名字标签 | **最该补**（P0-2，2–4 天）。它靠这个打「组队出行」场景 |
| **AI 生成行程** | 没有（我们只做「从你认可的笔记里挑」） | 可选。定位上我们刻意不做「从零生成」，但可以加「按偏好补几个点」 |
| 语音输入 | 没有 | 低优先（网页端收益小） |
| 附近推荐 | 有「看周边」（以住宿锚点为圆心） | 已够用 |
| 离线地图 | 没有 | 中（出行当天没网时有用） |
| 分享海报/长图 | 只有 HTML/文本/JSON | 中（发朋友圈要图，但可以后做） |
| 首页按阶段提示 | 没有 | 低（要日历+订单数据） |

## 五、结论

**它的强项是「AI 帮你从零排」+「多人一起改」；我们的强项是「从你已认可的笔记里挑」+「地图上真算耗时」+「数据在自己机器上」。**
这轮把「多条一起解析」「按天配色」「行程总览」补齐后，**单机规划这条链已经不输它**；
真正还差的是**协作**（它做透了，我们还没有）—— 这也是上一轮定位分析里排第一的 P0-2。
