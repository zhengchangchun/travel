# T6 需求增补：左右分离（「我的选择」独立到右栏）

> 2026-10-29 · 依据用户原话：「**我选中的放在右边吧，我选中的和左边正常全部的分开**」
> 前置：T1/T2/T3 已交付。

---

## §0 背景

现在所有东西都塞在**同一个左侧栏**里：城市、搜索、分类过滤、我的选择、我的行程、结果列表。
用户要把**「我挑的」**和**「全部（浏览用）」**分开 —— 「我的选择」挪到**右边独立一栏**。

## §1 目标布局（三栏）

```
┌──────────────┬───────────────────────┬──────────────┐
│  左：全部      │      中：地图          │  右：我挑的    │
│              │                       │              │
│ 城市          │                       │ 我的选择 (N)   │
│ 搜索地点      │   [高德地图]            │  只看我选中的  │
│ 分类过滤      │   分类色旗 / 路线折线    │  规划行程      │
│ ─────────    │                       │ ─────────    │
│ 结果列表(全部) │                       │ 行程列表 ↑↓    │
│              │                       │ 出行方式 步行/ │
│              │                       │   驾车/公交    │
│              │                       │ 总里程/耗时/分段 │
└──────────────┴───────────────────────┴──────────────┘
```

- **左栏** = 「全部」：城市选择、搜索地点、分类过滤、**结果列表**（浏览候选）
- **中栏** = 地图（占剩余宽度）
- **右栏** = 「我挑的」：我的选择(N)、只看我选中的、规划行程、行程列表（↑↓ 调序）、
  出行方式切换、路线总览（总里程/耗时/分段明细）

## §2 硬要求

| 编号 | 要求 |
|---|---|
| L1 | 三栏布局落地（左「全部」／中 地图／右「我挑的」） |
| L2 | 右栏**可折叠**（点按钮收起/展开），收起后地图变宽 |
| L3 | 左右两栏**各自独立滚动**；左栏列表再长也不影响右栏可见性 |
| L4 | 「我的选择」徽标数量、只看选中、行程 ↑↓、路线总览**全部迁到右栏**（左栏不许再残留） |
| L5 | 窄屏（< 1100px）：退回**上下/两栏**，可用即可（不要求三栏） |
| L6 | 地图宽度**自适应**（窗口变化、折叠时正常重排，AMap `resize()`） |

## §3 不做

- 不改后端与数据模型
- 不动路线算法/采集逻辑
- 不做拖拽调栏宽（固定宽度即可）
