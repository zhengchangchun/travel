## 一、从它身上量出来的东西

| 项 | 它的做法 | 我们原来 |
| --- | --- | --- |
| 底色 | **纯白** `#FFFFFF`，区块用极浅蓝 `#E4F0FC` / `#F0FCFC` 铺 | 暖黑 `#161614`（站点层）／浅灰 `#f4f5f7`（规划页） |
| 主色 | **天蓝** `#20D0F8`（标题里的强调词、路线、编号圆点、AI 按钮） | 铜橘 `#A8683C` |
| 地图 | **薄荷绿** `#D8F0D8` / `#CCE4B4`，白色道路，蓝色路线 | 高德默认底图 |
| 卡片 | 纯白、**大圆角 16–20px**、极淡阴影 `0 8px 24px rgba(20,40,60,.06)` | 直角 2px、发丝线 |
| 按钮 | 主 CTA 是**黑色胶囊**（「邀请微信好友」），次要是白底描边胶囊 | 方角、铜色实心 |
| 标签 | 白底描边**胶囊**，带小图标 | 方角小标签 |
| 标题 | 超粗黑体，**关键词用天蓝**（「告别繁琐 **极简出发**」） | 宋体 Black 暖白 |
| 留白 | 大留白、卡片之间 16–20px | 紧凑 |

## 二、新的设计令牌（替换掉暖黑那套）

```
--bg          #FFFFFF      页面底
--bg-soft     #F5FAFE      次级底（区块/侧栏）
--bg-tint     #E4F0FC      浅蓝铺底（首屏、强调块）
--surface     #FFFFFF      卡片
--line        #E6EDF3      分隔线（比发丝线淡）
--ink         #1A1D21      正文
--ink-2       #5A6470      次要
--ink-3       #8A94A0      弱
--accent      #20C8F0      天蓝（装饰、路线、编号）
--accent-deep #0E9FC4      天蓝深（**文字用这个**，白底上对比度够）
--accent-soft #E4F0FC      天蓝浅底
--map-green   #D8F0D8      地图薄荷绿
--radius      16px         卡片
--radius-sm   10px         输入/小卡
--pill        999px        胶囊
--shadow      0 8px 24px rgba(20,40,60,.06)
```

**对比度纪律**：天蓝 `#20C8F0` 在白底上只有 ~2.1:1，**不能当正文色**；正文/链接一律用 `--accent-deep #0E9FC4`（≈3.6:1，大字够用）或 `--ink`。装饰（线、点、底）才用亮天蓝。

## 三、分三步改（每步都能单独看效果）

| 步 | 范围 | 内容 |
| --- | --- | --- |
| **S1** | `site.css`（站点层：首页/行程/搭子/分享/设置/协作） | 换令牌：暖黑 → 白底＋天蓝；卡片圆角 2→16；按钮改胶囊；头部改白底毛玻璃 |
| **S2** | `home.css`（首页） | 首屏从「暖黑编辑风」改成「白底＋浅蓝渐变＋超粗黑标题（关键词天蓝）」；展示台/地区/卷轴/口碑全部换皮 |
| **S3** | `style.css`（规划页） | 铜橘 → 天蓝；直角 → 14px 圆角；地图底图换薄荷绿（高德自定义样式）；四类目色保留（语义色） |
