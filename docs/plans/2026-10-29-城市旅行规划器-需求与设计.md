## §0 背景与目标

**一句话**：一个网页工具，选一座城 → 看这座城的推荐地点 → 按分类筛选 → 落到地图上（不同分类不同小旗）→ 存成自己的行程。

**用户场景**：计划去某座城市旅行时，先把「想住的、想吃的、想玩的、想看的」都标在地图上，一眼看清分布，形成出行清单。

**定位**：个人自用工具（第一阶段），后台自己跑、本机访问。

**已确认边界**（用户 2026-10-29 明确）：

- ❌ **不做路线规划**（「路线规划先不走」）
- ✅ **要前后端**（「数据的话要前后端」）
- ✅ 分类 = **住宿 / 美食 / 游玩 / 景点**，且**要可扩展**（不写死 4 个）

---

## §1 用户主流程

1. **选城市** —— 搜索城市名 → 选中 → 地图切到该城（中心点 + 缩放）
2. **看推荐** —— 左侧列出该城的推荐地点（默认综合排序）
3. **分类过滤** —— 顶部 4 个分类 chip（美食 / 住宿 / 景点 / 游玩）→ 点击筛选列表与地图
4. **搜索定位** —— 搜索框输入关键词（如「西湖」「火锅」）→ 结果列表 → 点击 → 地图定位并落旗
5. **落旗** —— 每个点在地图上按**所属分类**显示不同颜色 / 图标的小旗
6. **看详情** —— 点小旗 → 信息卡：店名、**详细地址**、评分、人均、电话、营业时间、图片
   - 卡上有 `[导航]`（唤起高德）与 `[去小红书看笔记]`（跳转搜索页）
7. **存行程** —— 把点加入「我的行程」，落 SQLite，可再看、可导出

## §3 数据源决策（含实测证据）

### 3.1 结论

```
产品骨架 = 高德 POI（免费、稳定、有坐标、天然分类 → 直接落旗 + 过滤）
内容增强 = 小红书/抖音「跳转看 + 手动贴链接」，不做自动抓取
```

### 3.2 高德 POI 实测（2026-10-29，用用户提供的 key）

请求：`GET https://restapi.amap.com/v3/place/text?key=<key>&keywords=美食&city=杭州&extensions=all`

**可用字段**（真实返回，首条「牛New寿喜烧(来福士店)」）：

| 字段 | 值 | 产品用途 |
|---|---|---|
| `name` | 牛New寿喜烧(来福士店) | 旗子标题 / 列表项 |
| **`address`** | **新业路228号杭州来福士广场4楼** | **✅ 详细地址（用户明确要的）** |
| `location` | 120.212943,30.249170 | 落旗坐标 |
| `typecode` / `type` | 050202 / 餐饮服务;外国餐厅;日本料理 | 分类判定 |
| `biz_ext.rating` | 4.7 | 评分 |
| `biz_ext.cost` | 172.00 | 人均 |
| `tel` | 0571-86022015 | 电话（可点拨打） |
| `biz_ext.opentime2` | 周一至周日 11:00-14:30,17:00-21:30 | 营业时间 |
| `photos[].url` | 3 张 | 图片 |
| `tag` / `atag` | 虎皮凤爪,椒麻大虾,… | 招牌菜标签 |
| `business_area` / `adname` | 新城片区 / 上城区 | 商圈 / 区 |

逆地理编码实测同样可用，精确到门牌：`浙江省杭州市拱墅区米市巷街道环城北路318号`（带「南侧 14.9m」）。

**已知限制**：单次查询翻页上限 **200 条**（「杭州 美食」`count=600`）⇒ 要做「全量」需按区/商圈/分类分片，属正常工程手段。

### 3.3 小红书 / 抖音（实测被拒）

| 平台 | 实测结果 | 能否作数据源 |
|---|---|---|
| 小红书 | 搜索页返回「安全限制 · **IP存在风险** 300012」；主站无 `X-Frame-Options`（**技术上可被 iframe 内嵌**）但内容同样被 IP 风控挡 | ❌ 不能 |
| 抖音 | 搜索页弹**滑块验证**；响应头 `X-Frame-Options: DENY`（**禁止内嵌**） | ❌ 不能 |

补充根因：当前出口 IP 为 aTrust VPN 出口（`103.126.92.85`，网易香港机房），被平台判为高风险。即便如此，**自动抓取也不应作产品地基**（随时失效 + 合规风险）。

**本期采用的三条替代路径**：

1. 每个 POI 信息卡挂 `[去小红书看笔记]` → 新窗口打开 `xiaohongshu.com/search_result?keyword=<POI名+城市>`
2. 支持**手动贴笔记链接**入库（`POST /api/notes`），列表里与 POI 并列显示
3. 需要真·自动 → 只能买第三方数据服务（本期不做，见 §10）

## §4 技术选型

### 4.1 后端：Node.js 零 npm 依赖

| 项 | 值 | 理由 |
|---|---|---|
| 运行时 | Node.js v25.8.0（`/opt/homebrew/bin/node`） | 本机已有 |
| HTTP | `node:http` | 零依赖 |
| 数据库 | `node:sqlite`（**已实测可用**） | 零依赖，无需 native 编译 |
| 依赖 | **无 `node_modules`** | 无安装风险、无供应链风险、启动快 |

> 已实测：`node -e "const {DatabaseSync}=require('node:sqlite')..."` 通过。

### 4.2 前端：原生 + 高德 JS API

- 无构建步骤（原生 HTML/CSS/JS），后端直接静态托管
- 地图走高德 **JS API 2.0**（CDN：`https://webapi.amap.com/maps?v=2.0&key=…`）
- 已实测：同一把 key **既可用于 Web 服务（REST）也可用于 JS API**，地图初始化成功

## §5 数据模型

```sql
-- 行程
CREATE TABLE IF NOT EXISTS trips (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  city        TEXT NOT NULL,              -- 城市名，如「杭州」
  title       TEXT NOT NULL,
  created_at  TEXT NOT NULL DEFAULT (datetime('now'))
);

-- 已选点（从高德 POI 落下来的）
CREATE TABLE IF NOT EXISTS pins (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  trip_id     INTEGER NOT NULL REFERENCES trips(id),
  poi_id      TEXT,                       -- 高德 POI id
  name        TEXT NOT NULL,
  address     TEXT,                       -- 详细地址
  lng         REAL NOT NULL,
  lat         REAL NOT NULL,
  category    TEXT NOT NULL,              -- 分类 key：food/stay/sight/play
  rating      TEXT,
  cost        TEXT,
  tel         TEXT,
  photo       TEXT,
  note        TEXT,                       -- 用户备注
  created_at  TEXT NOT NULL DEFAULT (datetime('now'))
);

-- 手动贴的小红书/其它笔记链接（本期不做自动抓取）
CREATE TABLE IF NOT EXISTS notes (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  pin_id      INTEGER REFERENCES pins(id),
  city        TEXT,
  url         TEXT NOT NULL,
  title       TEXT,
  source      TEXT,                       -- xhs / douyin / other
  created_at  TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE INDEX IF NOT EXISTS idx_pins_trip ON pins(trip_id);
CREATE INDEX IF NOT EXISTS idx_notes_city ON notes(city);
```

## §6 接口契约

统一响应包装：`{ "ok": true, "data": …, "error": null }` / `{ "ok": false, "data": null, "error": {"code":…,"msg":…} }`
（HTTP 状态码同时正确表达：200 / 400 / 404 / 502）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 健康检查，返回 `{ok:true,data:{status:"up",…}}` |
| GET | `/api/config` | 返回前端需要的配置（**JS API key**、默认城市、分类定义） |
| GET | `/api/city/search?q=<关键词>` | 城市搜索（高德行政区划查询，只返回 city 层级） |
| GET | `/api/poi/search?city=<城市>&category=<分类key>&keywords=<可选>&page=<n>` | POI 关键词搜索 |
| GET | `/api/poi/nearby?lng=&lat=&category=<分类key>&radius=<米>` | POI 周边搜索 |
| GET | `/api/poi/detail?id=<poi_id>` | POI 详情 |
| GET | `/api/trips` | 行程列表 |
| POST | `/api/trips` | 新建行程 `{city,title}` |
| DELETE | `/api/trips/:id` | 删除行程 |
| GET | `/api/trips/:id/pins` | 某行程的点 |
| POST | `/api/pins` | 加点 `{trip_id,poi_id?,name,address,lng,lat,category?,rating?,cost?,tel?,photo?,note?}` |
| DELETE | `/api/pins/:id` | 删点 |
| GET | `/api/notes?city=<城市>` | 笔记链接列表 |
| POST | `/api/notes` | 加笔记链接 `{city,url,title?,pin_id?}` |
| DELETE | `/api/notes/:id` | 删笔记链接 |

**高德调用一律在后端**（`server/amap.js`），前端不直接打 restapi.amap.com —— 隐藏 Web 服务 key、统一缓存与错误处理。

## §7 分类配置（`config/categories.json`）

```json
{
  "categories": [
    { "key": "food",  "label": "美食", "amapCode": "050000", "color": "#FF6B35", "icon": "food"   },
    { "key": "stay",  "label": "住宿", "amapCode": "100000", "color": "#4A6CF7", "icon": "bed"    },
    { "key": "sight", "label": "景点", "amapCode": "110000", "color": "#22A06B", "icon": "camera" },
    { "key": "play",  "label": "游玩", "amapCode": "080000", "color": "#9B51E0", "icon": "play"   }
  ]
}
```

- 分类码取自高德 POI 分类体系（餐饮服务 `050000`、住宿服务 `100000`、风景名胜 `110000`、体育休闲服务 `080000`）
- **加分类只改这个文件**（前端 chip、旗子颜色、后端查询全部由它驱动）
- 高德一个分类码可能覆盖多个子类：实现时对 POI 的 `typecode` 做**前缀匹配**（如 `05xxxx` → 美食）

## §8 非功能要求

| 项 | 要求 |
|---|---|
| 端口 | 默认 `8787`，可配置 |
| Key 管理 | key 只放 `config/local.json`（gitignore）；仓库里只留 `config/example.json` 占位 |
| 配额保护 | POI 查询在**后端**缓存（同参数 10 分钟），避免重复消耗高德额度 |
| 错误处理 | 高德 `infocode != 10000` 时归一成 `{ok:false,error:{code,msg}}`，前端提示「请稍后重试」，不白屏 |
| 前端可用性 | 后端未启动时，页面显示明确报错，不静默白屏 |
| 依赖 | **零 npm 依赖**（不许出现 `package.json` 的 `dependencies`） |
| 兼容 | 窄屏（<800px）布局可用（上下结构） |
