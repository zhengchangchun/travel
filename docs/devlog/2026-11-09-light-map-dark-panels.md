# devlog 2026-11-09 · 地图改亮底，两侧栏留暗色并加点设计

## 触发

用户：「地图底板要亮色的，左右两边需要有点设计的暗色」。提交 `3c1ff38`。

## 改法

**地图（亮）**
- `map.js`：`mapStyle` 从 `amap://styles/dark` 改回标准亮色 `amap://styles/normal`。
- `#map-wrap` 背景色 `#0a0c11` → `#eef1f6`（瓦片加载前/边缘也是亮色，不会闪一块黑）。
- 地图上的浮层（视野计数、状态条、评分图例、信息卡）本来就是深色玻璃拟态，亮底上反而更清楚，不动。

**两侧栏（暗色 + 设计）**
- 背景从「单层线性渐变」升级成 **4 层**：
  ① 外侧上角的主色晕（左栏左上 `rgba(109,139,255,.13)`、右栏右上同色）；
  ② 对角另一种色晕（左栏右下青 `rgba(53,208,192,.10)`、右栏左下金 `rgba(255,210,63,.07)`）；
  ③ **20px 点阵纹理**（`rgba(255,255,255,.075)` 的 1px 圆点）；
  ④ 深色纵向线性渐变 `#12161f → #0d1016`。
- 分隔与层次：内侧 1px 高光（`inset ±1px 0 rgba(255,255,255,.05)`）+ 朝地图一侧的柔和投影
  （`±10px 0 30px rgba(0,0,0,.35)`），让两栏像「浮」在亮地图上。
- 品牌区加一条**渐变发丝线**（蓝→青，向右淡出）做结构；`.brand` 加 `padding-bottom: 10px` 配合。

## 验收（真预览 8787、1600×1000）

- `map-wrap` 背景 `rgb(238,241,246)`；左栏/右栏背景 `rgb(13,16,22)` 且 `background-image` 各 **4 层**；
  左栏 inset 高光生效、`.brand::after` 是蓝→青渐变。
