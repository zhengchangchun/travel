# devlog 2026-11-09 · 住宿锚点支持多个

## 触发

用户：「住宿锚点可能是多个」（一个行程会换酒店 / 分几段住）。提交 `8b3abd8`，之后两笔修复
（`c1f0aa1` 卡片不展开、`153a439` 旗子重画）。

## 改法

- **数据**：`state.bases: [...]`（可多个）+ `state.base`（其中「当前」那个）。持久化键 `travel.bases` /
  `travel.baseActiveId` / `travel.baseRadiusM`；老的单锚点键 `travel.base` 首次加载时**自动迁移**过去，之后清掉。
- **卡片**：多一个 `#base-list`。每行 = 名字（点一下设为当前）+ `×`（删这一个）；
  标题条 1 个时显示名字、多个时显示「N 个」；副行显示「当前 X · 周边 1 km（异地城市还会标城市）」；
  没有锚点时三个按钮（看周边 / 回中 / 清除）都置灰，「清除」= 清空全部。
- **语义**：「看周边」「回中」「自动成线起点」都用**当前**锚点；地图上**所有**锚点都打金框 + 「住」角标。
- 点「住这」在已是锚点的酒店上 = **取消它**（跟按钮的「★住这」选中态一致）。
- `map.js`：`baseId` 改成 `baseIds` 数组，`setBase(ids)` 收数组（向后兼容单个）。

## 两个自己踩的坑

1. **加了锚点卡片却没展开**：原来的判断写在「已经 push 进 bases」之后 ⇒ `cardExpanded('base')` 恒为真，
   于是永远不展开，用户看不到刚加的列表。修法＝加完直接把 `cardState.base = true` 并 `applyCardState()`。
2. **地图旗子不换样子**：`syncMarkers` 只建「还没有的」旗子，已落图的不会重建 ⇒ 刚变成锚点的那面旗
   还是一片普通旗（没有金框/住角标），要等下次整屏重建。修法＝`setBase()` 里比较前后集合，
   只对「刚加入 / 刚移出」的那几面 `setContent(flagHtml(...))` 重画（`extData` 里补存 `selected` 才能重画对）。
