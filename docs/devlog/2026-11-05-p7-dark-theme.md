# devlog 2026-11-05 · P7 暗色主题（时髦一点的皮）

## 触发

用户：「想要点暗色系设计 感觉这个设计不太时髦」。

## 做法（追加层，不动老规则）

`web/css/style.css` 末尾**追加**一段 `:root` 令牌 + 覆盖层（老规则一条没删）：
- 令牌：底 `#0b0d12` / 面板 `#101319` / 卡片 `#151922` / 描边 `rgba(255,255,255,.07)` /
  文字三档 `#e9edf6·#a7b1c0·#6f7887` / 强调色靛蓝 `#6d8bff` → 青 `#35d0c0`；
- 时髦的三件：**玻璃拟态浮层**（地图状态/视野计数/详情卡：`backdrop-filter: blur(12–16px)`）、
  **渐变主按钮**（靛蓝→青，带柔光阴影）、**细描边＋圆角收敛＋统一过渡**（hover 抬起 1px）；
- 暗色底图：`map.js` 初始化加 `mapStyle: 'amap://styles/dark'`（不然深色界面里嵌一块惨白地图）；
- 细节：暗色滚动条、`color-scheme: dark`（表单原生控件跟着变暗）、旗子描边加密、评分色阶图例改成暗底梯度。

**为什么选择追加而不是重写**：既有 620 行里有 5 处被测试钉住的选择器（`.check`、`.flag.base .flag-head`、
`.flag-base`、`.collapsed`/`1100px`、`.view-hint` 等），追加层零风险；将来想回浅色只要删这一段。
