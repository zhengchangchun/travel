# devlog 2026-11-09 · 去掉「显示全部」空态引导与「全部」分类

## 触发

用户贴了结果区那张「还没选分类：点上面的分类开始，或 [显示全部]」的截图：
「不要这个显示全部 过滤那个也不要全部」⇒ 两件事一起删。提交 `f4a1fac`（＋补丁 `22a846e`）。

## 改法

1. **空态引导删掉**（`app.js::refresh`）：未选分类时列表就是空的；只有「倍率不够」才留一句
   「放大地图以加载本区域地点」（那是另一种、可操作的状态）。
2. **「全部」chip 删掉**（`renderCatChips`）＝只剩四个真实分类；顺带把藏在后面的 `state.showAll` 整个删掉
   （它是「勾了全部」的隐藏模式），于是：
   - `passesCat`：没选就不显示，选了只看选中的；
   - `catFilterEmpty`：`activeCats.size === 0`；
   - `filterText`：四个都选中 ⇒ 汇总写「全部分类」（否则列名字）；
   - **关键词搜索**：不再翻隐藏开关，而是把四个分类一次性选中 ⇒ 列表与 chip 说的是同一件事（四个都亮）。
3. **CTA 的残余代码一起清**：`ui.js::renderResults` 不再支持 `emptyAction`，`.empty-cta` 样式删掉
   （测试改成钉「没有 CTA」「没文案就不渲染」）。
4. 顺手修了新引入的排版回归（`22a846e`）：标题条右侧那组是按内容宽的，里面的 `.bar-note` 还按「标题条 46%」量
   ⇒ 折叠态被截成「未…」「本…」；改成组内固定 `max-width: 132px`。
