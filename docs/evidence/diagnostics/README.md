# POI 覆盖诊断（2026-10-29）

问题（用户）：很多店铺在列表里没有，但地图上能看到 —— 是没在高德登记吗？

**结论：不是没登记。是高德搜索接口的取数上限。**

## 实测

`poi-recall.py`：
- 关键词搜索「杭州 美食」→ `count=600`，但**翻页只能到第 8 页**（25×8＝200 条），第 20 页返回 0
- ⇒ 单次查询**最多 200 条**

`poi-coverage.py`：
- 城市级「美食」搜索拿到 200 条（去重 200）
- 在 3 个点各做 1km 周边搜索（各 25 条）：
  | 位置 | 周边 25 条中，城市级搜索**拿不到**的 |
  |---|---|
  | 来福士 | **18** |
  | 西湖 | **25** |
  | 火车东站 | **25** |
- 合计 **68 家**店：周边搜得到、城市级搜索搜不到
- 例：`蔡澜港式点心(杭州来福士店)`、`肯德基(火车东站店)`、`小杨生煎(杭州东站西广场店)`

## 结论

- 高德**有**这些数据（地图底图按当前视野实时渲染，所以用户能看到）
- 但**搜索接口**单条件最多回 200 条，按相关性排序 ⇒ 权重低的小店铺排在 200 名以外，列表里就没有
- **修法**：按视野/网格分片做周边搜索（每次 200 条 × N 个网格），覆盖可大幅提升

## 另测

`amap-click-poi.cjs`：AMap JS API 2.0 的 `map.on('click')` 事件**不含 `e.poi`**
（只有 `lnglat/target/pixel/originEvent/pos/type`）⇒ 「点底图店铺直接选中」不可行；
替代＝**点地图任意位置 → 以该点做周边搜索，列出最近的店让用户选**。
